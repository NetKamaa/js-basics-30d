# Day 07 — Quiz

## 1. Чем отличается `filter` от `splice` по эффекту на массив?

`filter` возвращает новый массив и не изменяет исходный.
`splice` изменяет исходный массив (мутирует его), удаляя или добавляя элементы.

---

## 2. Почему удаление по id лучше, чем по индексу?

Индекс может измениться после сортировки или фильтрации массива. `id` — это стабильный уникальный идентификатор, который не зависит от позиции элемента.

---

## 3. Что такое «чистая функция» на примере проекта?

Чистая функция — это функция, которая при одинаковых входных данных всегда возвращает одинаковый результат и не изменяет внешнее состояние.

Например, функция, которая принимает массив задач и возвращает новый массив отфильтрованных задач без изменения исходного массива.

---

## 4. Где должен жить `render()` и что он НЕ должен делать?

`render()` должен жить в слое, отвечающем за отображение (UI).

Он не должен изменять данные, хранить бизнес-логику или мутировать состояние — только получать данные и отображать их.
